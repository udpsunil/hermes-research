NAND Flash Glossary

Reference · The vocabulary every SSD debug conversation uses. Keep this open while reading any paper.

The Physical Hierarchy

TermMeaningWhy a debug architect cares
CellSingle floating-gate (or charge-trap) transistor storing 1–4 bits via threshold voltageBit errors originate here; cell type sets endurance budget
PageSmallest readable/programmable unit (4–16 KB typical)Reads and programs happen at page granularity — never smaller
BlockSmallest erasable unit (64–512 pages, several MB)Erase-before-write rule lives here; GC operates on blocks
PlaneIndependent array within a die; each has its own registersPlanes can operate in parallel — a latency lever
DieOne silicon chip; contains 2–4 planesDies share a channel; a bad die = capacity loss
Way / CEOne die position on a channel (chip enable)Channels × ways = total parallelism of the drive
ChannelShared data bus connecting controller to several diesChannel contention is a classic latency root cause

Cell Types & Endurance

TypeBits/cellP/E cycles (typ.)Trade-off
SLC1~100,000Fastest, most durable, most expensive per GB
MLC2~3,000–10,000Balanced legacy choice
TLC3~1,000–3,000Mainstream today; tighter voltage margins
QLC4~300–1,000Cheapest per GB; weakest endurance, slowest writes

Fewer bits per cell = wider voltage separation between states = fewer misreads = more endurance.

Operations & Rules

Program (write)
Charge floating gate to raise threshold voltage. Page-granularity, sequential within a block.
Erase
Clear all cells in a block to the erased state. Block-granularity, slow (~ms).
Erase-before-write
A programmed page cannot be rewritten until its whole block is erased. The reason FTL exists.
P/E cycle
One program+erase round trip on a block. Oxide degrades each cycle → wear.
Read disturb
Repeated reads bias neighboring cells' thresholds upward → errors. Fixed by block rewrite.
Retention error
Charge leaks over time (worse hot, worse after many P/E cycles) → errors on old data.
Program disturb
Programming one page shifts thresholds on neighbors in the same block.

Error Management

  • ECC (BCH/LDPC): corrects bit errors within a page; uncorrectable = UBER event
  • Bad block: factory-marked at test, or "grown" during life; replaced from spare pool
  • RBER: raw bit error rate before ECC — a key health telemetry signal
  • UBER: uncorrectable bit error rate — data corruption that ECC couldn't fix
